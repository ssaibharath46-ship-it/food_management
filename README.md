# FoodRescue — Food Waste Management System

## Tech
HTML5 + CSS3 + JavaScript + Local Storage

## Modules
- Admin
- Donor
- Recipient / NGO
- Volunteer-ready role

## Main features
- Login & Signup using Local Storage
- Role-based dashboards
- Post surplus food
- 24-hour maximum listing
- Earlier expiry support
- Automatic expiry
- Urgent expiry alerts
- Smart priority matching
- Search and filters
- Food claim workflow
- Donation history
- Admin analytics
- Impact statistics
- Responsive CSS Grid/Flexbox UI

## Demo
1. Open `index.html`.
2. Create a donor account.
3. Post food.
4. Open Find Food and claim it using another recipient account.
5. For Admin, use `admin@foodrescue.com` / `admin123`.
6. Admin can use **Add Demo Data** to populate a sample donation.

## Important
The 24-hour rule is a maximum listing period, not a food-safety guarantee. A donor's earlier expiry time takes priority.
